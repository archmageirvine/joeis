# A069481: finite rational matrix groups

Build the usual jOEIS JAR and run:

```sh
ant jar
java -Xmx896m -XX:ActiveProcessorCount=2 -jar build.tmp/joeis.jar -n 31 A069481
```

The JAR includes the structural records. Neither a data path nor any
network or non-Java runtime is needed. No OEIS values, catalogue
maximality map, or verdicts about individual containments are stored.

## What the program computes

- Dimensions 1–6 start from the [CARAT rational catalogue](https://github.com/lbfm-rwth/carat/blob/65619d6ae4ec911c8cf7aa3c9fa09866a0d36ab9/tables/qcatalog.tar.gz).
  The resource keeps **every** generator record, including the nonmaximal
  classes, and removes the maximality labels. The Java code tests proper
  containment.
- Dimensions 7–31 use generators, forms, short vectors and group types
  from the [GAP IMF library](https://docs.gap-system.org/doc/ref/chap50.html).
  The catalogue and the classification supply the candidate universe;
  the program does not re-prove the completeness of that list. The
  Java code resolves each possible proper containment by exact group,
  representation and lattice calculations. It throws if a comparison
  is unresolved and stops at the catalogue's dimension limit.
- The other records supply group data for these checks: actual class
  representatives and sizes, quotient Cayley graphs, subgroup generators
  and marked elements. In particular, the Leech spectra come from the
  degree-24 character of [2.Co1 in CTblLib](https://www.math.rwth-aachen.de/~Thomas.Breuer/ctbllib/ctbltoc/data/2.Co1.html),
  using class power maps and Newton's identities. The 160 masses agree
  with [Chenevier's independent census](https://doi.org/10.5802/jtnb.1134).

## Data resources

The files in `src/irvine/math/group/resources` are included by the
existing jOEIS group-resource build rules. The copyright and license
notices are in [a069481-data-license.dat](../src/irvine/math/group/resources/a069481-data-license.dat).

```text
1215339578e6f4cdac26b5b58d759221b4300e40d835edb19c0f1c2fb154f476  a069481-carat.dat.gz
004796c719ab632a5ff0a127ce4d9e6e70a4ece8b792edbe745d948376bb0afb  a069481-imf.dat.gz
```

The CARAT resource is a standard compressed tar of the original
generator records. The IMF resource is compressed UTF-8 text: each
section starts with `@@ filename.txt`. Both may be decompressed and
inspected without jOEIS. To repack them, extract the IMF text sections
into a records directory and put the original CARAT `qcatalog.tar.gz`
there. Then run:

```sh
python3 tools/a069481-leech.py ctbllib-1.3.11.tar.xz > LeechMasses.txt
python3 tools/pack-a069481.py records src/irvine/math/group/resources --leech LeechMasses.txt
```

The [CTblLib source archive](https://deb.debian.org/debian/pool/main/g/gap-ctbllib/gap-ctbllib_1.3.11.orig.tar.xz)
is needed only if regenerating the Leech data, not to run the sequence.
The standard test suite checks the first five terms. The full replay
compares all 31 values with [the OEIS b-file](https://oeis.org/A069481/b069481.txt)
after computing them; the b-file is not a solver input.
