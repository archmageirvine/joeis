# A069481: finite rational matrix groups

The sequence runs in Java, using a local directory of structural group
records. It does not read an OEIS term table, use stored maximality
decisions, launch GAP, or fetch anything at run time.

```sh
java -Xmx896m -XX:ActiveProcessorCount=2 \
  -Djoeis.a069481.data=/path/to/structural-records \
  -Djoeis.rational.audit.chainCells=59000000 \
  -jar joeis.jar -n 31 A069481
```

The branch does not vendor the data. In particular, the GAP IMF library
has its own GPL-2.0-or-later notices. The input hashes below identify the
offline data directory used for verification and are not answer hashes.
Availability and redistribution of the complete input bundle remain
points for review before this draft is marked ready.

## Structural inputs and computation

- Dimensions 1–6 use the [CARAT rational catalogue](https://github.com/lbfm-rwth/carat/blob/65619d6ae4ec911c8cf7aa3c9fa09866a0d36ab9/tables/qcatalog.tar.gz).
  The reader considers the generator records for all rational classes,
  including nonmaximal classes. It computes containments itself.
- Dimensions 7–31 use generator matrices, invariant Gram matrices, group
  orders, short-vector seeds, and types from the
  [GAP IMF library](https://docs.gap-system.org/doc/ref/chap50.html).
  The classification supplies the candidate universe; the Java code does
  not re-prove its completeness. The exported fields do not include the
  rational-maximality map. In dimension 7 the code checks the signed
  simplex embedding in the generated E7 root model.
- The remaining files supply finite-group structural certificates:
  class representatives with class sizes, normal-subgroup generators,
  quotient Cayley graphs, Sylow generators, and a few marked group
  elements. The Leech table supplies class masses, not candidate
  decisions. The Java code computes matrix spectra and tests actual
  subgroup and lattice obstructions. These inputs were derived offline
  using the IMF library, Weyl groups, and published
  [ATLAS](https://brauer.maths.qmul.ac.uk/Atlas/) group information.
- On an unresolved possible containment the implementation throws instead
  of reporting the surviving candidate count. It stops after dimension
  31, the last dimension covered by the supplied classification.
